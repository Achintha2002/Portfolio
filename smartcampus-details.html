Project Title

Smart Campus Hub

Comprehensive Operations & Resource Management

Overview

The Smart Campus Operations Hub is a comprehensive full-stack web application designed to streamline university resource management and incident reporting. It provides a centralized platform for users to book campus facilities and equipment, report campus incidents, and receive real-time updates, effectively solving the problem of fragmented and inefficient campus operations.

Unified Dashboard

A clean, intuitive React interface for seamless resource bookings and real-time updates.

Core Security Feature

Google OAuth 2.0 Authentication

Engineered a highly secure, passwordless authentication flow. Integrated Google OAuth 2.0 utilizing a stateless JWT session management approach. This effectively bypasses the need for traditional CSRF tokens while providing a seamless user login experience and robust backend protection via Spring Security.

Features

Core Functionalities

Resource Booking Engine

Allows users to request reservations for campus resources with built-in conflict detection and a dedicated admin approval/rejection workflow.

Incident Ticketing System

Enables users to report issues with up to 3 image attachments (max 5MB each), utilizing secure file storage and path traversal protection.

Auto-triggered Notification System

Sends automated, real-time alerts for booking status updates and incident progress, featuring a React-based notification panel with an unread badge counter.

Role-Based Access Control (RBAC)

Secures endpoints by restricting sensitive actions—like status approvals and global data viewing—strictly to users with ADMIN privileges.

Deep Dive

Engineering Complexities

Backend Architecture

Implements a robust structural pattern separated into distinct layers: Entities, Repositories, Services, Controllers, DTOs, and Exceptions. This ensures a clean separation of business logic, database operations, and API routing.

The Spring Boot backend exposes well-defined RESTful endpoints that the React Single Page Application (SPA) consumes asynchronously via Axios. It utilizes Spring Data JPA with Hibernate for seamless ORM and schema management.

  • Layered MVC Architecture
  • Automated Data Modeling with JPA
  • RESTful API SPA Integration

Advanced Conflict Detection

Engineered complex JPQL overlap queries to ensure no double-booking of resources occurs. This required handling intricate date-time overlap logic efficiently at the database level rather than the application level.

Secure File Handling & Validation

Implemented robust file upload mechanisms featuring UUID-based filename generation to prevent path traversal attacks. This is coupled with strict MIME-type validation (accepting only image/*) before routing to Supabase Storage Buckets.

Scalable Database Connectivity

Integrated a Supabase Transaction Pooler (PgBouncer proxy on port 6543) instead of a direct connection. This architectural decision optimizes database performance and gracefully handles concurrent PostgreSQL connection scaling under high load.
