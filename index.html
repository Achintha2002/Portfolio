WEB APP

BrightPath LMS

A comprehensive, full-stack Learning Management System designed specifically for the Sri Lankan university ecosystem.

Tech Stack

Frontend: Vue 3, Vite, Tailwind CSS, Pinia, Vue Router, Axios
Backend: Python, Django 6.0, Django REST Framework, SimpleJWT
Database: SQLite (Dev) / PostgreSQL (Prod)
Cloud & Tools: Celery, Redis, Django-Celery-Beat, AWS S3
Processing: PyTesseract (OCR), PyPDF2, python-docx, ReportLab

Key Features

  • Role-Based Access: Secure registration for Students, Lecturers, and Staff with NIC verification.
  • Digital Library & Points: Centralized repository with a gamified "Points Wallet" to encourage engagement.
  • Live Kuppi Sessions: Modules for scheduling, managing, and discovering peer-led tutoring.
  • Smart Notifications: Context-aware, asynchronous email and in-app alerts.
  • AI Recommendations: Intelligent engine suggesting relevant study materials based on user activity.

Architecture

  • Decoupled SPA: Vue 3 frontend communicating via RESTful API.
  • API-First Design: Django Model-View-Serializer architecture with DRF.
  • Asynchronous Task Queue: Celery + Redis architecture for heavy operations.
  • Stateless Authentication: JWT for secure API communication.

Engineering Challenges

Asynchronous Task Orchestration

Implementing Celery and Redis to safely offload time-consuming tasks like email notifications and recommendation calculations without blocking the main thread.

Document Parsing & OCR

Building complex pipelines using PyTesseract and PyPDF2 to parse text from uploaded resources and verify student/lecturer IDs via automated OCR.

Custom AI Recommendation Engine

Engineering a scalable engine to aggregate metrics across the student body and generate dynamic content suggestions in the background avoiding DB lockups.
