Project Title

BrightPath LMS

Interactive Live Kuppi Sessions & Peer-led Learning

Overview

BrightPath LMS is a comprehensive, full-stack Learning Management System designed specifically for the Sri Lankan university ecosystem. It bridges the gap between students, lecturers, and staff by providing a centralized digital library, live peer tutoring (Kuppi) management, and intelligent content recommendations, ultimately streamlining the academic experience and fostering collaborative learning.

Modern Student Dashboard

Clean, intuitive UI for peer tutoring and resource access.

Core Functionalities

Role-Based Access & ID Verification

Secure registration for Students, Lecturers, and Staff with Sri Lankan NIC verification and tailored dashboard experiences.

Digital Library & Points Wallet

Centralized repository with a gamified Points Wallet to encourage material uploads, engagement, and knowledge sharing.

Live Kuppi (Peer Tutoring)

Dedicated modules enabling students to seamlessly schedule, manage, and discover peer-led tutoring sessions.

Smart Automated Notifications

Context-aware, asynchronous email and in-app notifications to alert users about newly uploaded resources or feedback requests.

AI Resource Recommendations

Intelligent engine analyzing user activity to dynamically suggest relevant study materials tailored to their courses.

Decoupled Architecture

Modern Vue 3 SPA frontend communicating securely with a Django Model-View-Serializer REST API via stateless JWT authentication.

Deep Dive

Engineering Complexities

Asynchronous Task Orchestration

Implementing Celery and Redis was a crucial engineering challenge. This architecture safely offloads time-consuming tasks—such as broadcasting HTML-rich email notifications, dispatching periodic user feedback requests, and crunching peer recommendations—without blocking the main thread. This ensures the API remains highly responsive under heavy student load.

Custom AI Recommendation Engine

Engineering a scalable RecommendationEngine that aggregates user activity metrics across the entire student body. The complexity lied in efficiently querying the activity data and generating relevant suggestions in the background via update_peer_recommendations_task, avoiding database lockups during peak traffic.

Document Parsing & OCR

Integrating advanced file handling using PyTesseract, PyPDF2, and python-docx. We built complex pipelines to parse text from diverse study materials and automated the Optical Character Recognition (OCR) verification of Student ID cards.

  • Automated ID verification pipelines
  • Multi-format document parsing (PDF, Word)
  • Report generation via ReportLab
