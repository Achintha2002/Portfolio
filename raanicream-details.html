Overview

Raani Cream is a modern, fully-featured MERN stack e-commerce web application built for a premium skincare brand. It provides a seamless shopping experience for customers with a beautiful interactive product catalog, and a comprehensive administrative dashboard for store managers to handle order fulfillment, inventory tracking, and sales analytics.

Interactive Skincare Store

Beautiful organic theme featuring dynamic shopping carts and smooth micro-animations.

Features

Core Functionalities

Interactive Product Catalog

Displays premium products with filtering capabilities, detailed views, and smooth micro-animations to enhance user experience.

Dynamic Shopping Cart

Features a sliding drawer UI for real-time cart updates, providing a seamless checkout process without unnecessary page reloads.

Secure Authentication System

Includes user registration, login, protected route access, profile management, and password recovery using JWT securely.

Admin Analytics Dashboard

Delivers real-time insights into total sales, order status ratios, and best-selling products for store administrators.

Order & Inventory Management

Allows admins to process customer orders, update shipping statuses, adjust stock levels manually, and receive automated low-stock alerts.

Customer Communication Portal

Direct inquiry submission system allowing customers to contact the store, with admins able to view and reply directly from the dashboard.

Deep Dive

Engineering Complexities

Complex Checkout & Email Integration

Handling order creation involves not only saving the transaction to the database but also dynamically generating and dispatching a visually structured HTML email receipt to the customer using Nodemailer. This requires careful error handling to prevent the entire checkout process from failing if the email service times out.

Secure Authentication & Route Protection

Designing a robust authentication flow using JSON Web Tokens (JWT). The backend employs custom protect and authorize middleware to restrict endpoint access based on user roles (Admin vs User), while the frontend manages local storage and React context to persist secure sessions.

Architecture & State Synchronization

The application is split into two distinct repositories (client and server), allowing independent scaling and deployment on Vercel and Render. The backend strictly follows a decoupled MVC-inspired structure.

A major frontend challenge was implementing Real-time State Synchronization. The dynamic shopping cart uses a sliding drawer UI that seamlessly syncs with the global CartContext across different components (like the navigation badge and checkout page) without causing unnecessary re-rendering bottlenecks.

  • Independent Client/Server deployments
  • Global Context State Management
  • Responsive UI with Framer Motion Micro-Animations
