Overview

Sportify is a robust, full-stack e-commerce platform designed exclusively for sports equipment and gear. It solves the complexity of multi-vendor retail by providing a seamless, role-based ecosystem that connects customers, system administrators, and suppliers through dedicated dashboards, streamlined order fulfillment, and automated inventory management.

Features

Core Functionalities

Role-Based Access Control (RBAC)

Features dedicated, isolated workflows and dashboards for three distinct user types: Customers (shopping & tracking), Admins (platform oversight), and Suppliers (inventory & fulfillment).

Dynamic Product Catalog & Search

Implements advanced browsing with text-indexed search capabilities, filtering by categories/brands, and dynamic calculation of discounted prices.

Automated Inventory & Alert System

Monitors stock levels in the background and automatically dispatches formatted emails and in-app notifications to suppliers when product quantities fall below defined reorder points.

Comprehensive Order Management

Supports an end-to-end checkout flow with Stripe payment integration, alongside a detailed order tracking system that handles everything from shipment processing to refunds.

Data Visualization & PDF Reporting

Allows Admins and Suppliers to track sales performance via Chart.js and generate downloadable PDF reports directly from their dashboards using aggregated database statistics.

Cloud Image Infrastructure

Utilizes Cloudinary for highly optimized, persistent cloud storage of all product catalogs and user profile imagery to ensure fast loading times.

Deep Dive

Engineering Complexities

Automated Background Processes (Cron Jobs)

Orchestrating real-time inventory monitoring required implementing node-cron. The backend executes scheduled background jobs that run complex database queries to identify low-stock items. This immediately triggers a concurrent workflow to compile HTML email templates and dispatch them via Nodemailer without blocking the main event loop.

Transactional Integrity & Payments

Handling the checkout process required a highly synchronized state machine. The system seamlessly transitions cart data from the frontend, validates pricing against the database, securely processes transactions via the Stripe API, and subsequently triggers updates to inventory levels, shipment statuses, and supplier ledgers while accounting for refunds and cancellations.

Architecture & Aggregations

The backend strictly adheres to a modular MVC pattern. The API relies on custom middleware chains for JWT verification, role authorization, and file uploading via Multer before controllers execute business logic.

To power the analytical dashboards, the application utilizes MongoDB Aggregation Pipelines ($group, $sum, $avg). This enables the database engine to rapidly compute revenues and order statuses without overloading the Node server's memory.
